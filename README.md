# Classification-Means-Transport
Este repositorio presenta la metodologia para llevar a cabo la clasificacion del medio de transporte utilizando modelos de aprendizaje automatico

# Resumen

Para llevar acabo esta tarea de clasificación se empleo un dataset de alrededor de 5034 registros con información sobre los patrones de movilidad. Incluye preguntas sobre información personal y detalles sobre los desplazamientos de los participantes. El primer paso fue preparar el dataset mediante una limpieza del mismo. Posterior a esto se empleo técnicas de apredozaje automático para poder preparar el dataset y alimentar a los diferente modelos. Tres modelos de aprendizaje automático fueron empleados: Random Forest, Decision Tree y Xgboost. Se comparo los resultado de estos tres modelos y se pudo ver que el mejor modelo fue Random Forest.
